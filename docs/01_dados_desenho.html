Objetivo

Apresentar os dados simulados utilizados no projeto e definir o desenho comum que será empregado pelos métodos de predição genômica.

A primeira etapa do projeto mantém os 1.000 indivíduos disponíveis e avalia a redução do número de marcadores (p). Os subconjuntos de marcadores serão definidos posteriormente a partir dos rankings de importância produzidos pelos modelos usando exclusivamente os indivíduos de treinamento.

Neste módulo são definidos:

  • os dados fenotípicos e genotípicos;
  • os valores genéticos verdadeiros;
  • os seis cenários simulados;
  • o mapa genético;
  • os níveis de redução de p;
  • uma única validação cruzada de cinco folds, fixa e comum a todos os métodos.

1. Dados simulados

Os dados foram previamente simulados no software GENES para uma população F2 com 1.000 indivíduos e 4.010 marcadores distribuídos em 10 grupos de ligação.

Cinco arquivos são utilizados diretamente nesta análise:

  • DG#gen_F2_Vfen.txt: fenótipos;
  • DG#gen_F2_Vgen.dat: valores genéticos verdadeiros;
  • genoma_mapa.txt: genótipos;
  • genoma.txt: mapa genético;
  • controlegenetico#1.dat: parâmetros dos seis cenários e posições dos QTL.

Os demais arquivos originais são preservados em data/dados_simulados/, mas não são necessários para construir o objeto analítico utilizado pelos modelos.

3. Cenários genéticos

O arquivo de controle registra os parâmetros utilizados na simulação. Cada bloco corresponde a uma das seis características analisadas.

controle_linhas <- readLines(
  file.path(dados_dir, "controlegenetico#1.dat"),
  warn = FALSE,
  encoding = "latin1"
)

inicio_blocos <- grep("^Variavel", controle_linhas)

valor_campo <- function(linha) {
  partes <- strsplit(linha, ",", fixed = TRUE)[[1]]
  as.numeric(trimws(partes[length(partes)]))
}

qtl_por_cenario <- setNames(
  lapply(
    inicio_blocos,
    function(inicio) {
      scan(
        text = controle_linhas[inicio + 3L],
        what = integer(),
        quiet = TRUE
      )
    }
  ),
  paste0("C", seq_along(inicio_blocos))
)

controle_cenarios <- do.call(
  rbind,
  lapply(
    seq_along(inicio_blocos),
    function(i) {
      inicio <- inicio_blocos[i]

      data.frame(
        cenario = paste0("C", i),
        variavel = as.integer(valor_campo(controle_linhas[inicio])),
        total_loci = as.integer(valor_campo(controle_linhas[inicio + 1L])),
        n_qtl = as.integer(valor_campo(controle_linhas[inicio + 2L])),
        gmd = valor_campo(controle_linhas[inicio + 5L]),
        modelo = as.integer(valor_campo(controle_linhas[inicio + 6L])),
        h2 = valor_campo(controle_linhas[inicio + 7L]),
        constante = valor_campo(controle_linhas[inicio + 8L]),
        escala = valor_campo(controle_linhas[inicio + 9L]),

4. Redução inicial do número de marcadores

Nesta primeira etapa do projeto, todos os 1.000 indivíduos são mantidos. A dimensão reduzida é apenas p.

O conjunto completo de 4.010 marcadores representa a condição de referência. Os demais tamanhos correspondem aos percentuais de marcadores mais importantes segundo cada método.

O M01 não seleciona marcadores. Para cada cenário, método e fold, o modelo será primeiro ajustado com os 4.010 marcadores disponíveis no treinamento. O ranking de importância produzido nesse ajuste definirá os painéis reduzidos.

Assim, para um mesmo ranking:

\[ P_{1\%} \subset P_{5\%} \subset P_{10\%} \subset P_{25\%} \subset P_{50\%} \subset P_{100\%}. \]

Os rankings serão específicos para cada combinação de cenário, método e fold.

5. Validação cruzada comum

Todos os métodos utilizarão a mesma partição dos indivíduos. Será empregada uma única validação cruzada de cinco folds.

A formação dos folds depende somente do identificador dos indivíduos e de uma semente fixa. Fenótipos, valores genéticos verdadeiros, genótipos e posições de QTL não participam da geração das partições.

SEED_DESENHO <- 20260908L
N_FOLDS <- 5L

set.seed(SEED_DESENHO)

ordem_individuos <- sample(
  ids,
  size = length(ids),
  replace = FALSE
)

fold_na_ordem <- rep(
  seq_len(N_FOLDS),
  length.out = n_individuos
)

fold_individuo <- integer(n_individuos)
fold_individuo[ordem_individuos] <- fold_na_ordem

atribuicao_folds <- data.frame(
  id = ids,
  individuo = id_individuo,
  fold = fold_individuo,
  stringsAsFactors = FALSE
)

folds <- setNames(
  lapply(
    seq_len(N_FOLDS),
    function(k) {
      list(
        fold = k,
        treino = ids[fold_individuo != k],
        teste = ids[fold_individuo == k]
      )
    }
  ),
  paste0("Fold", seq_len(N_FOLDS))
)

stopifnot(
  all(table(atribuicao_folds$fold) == 200L),
  all(vapply(folds, function(x) length(x$treino) == 800L, logical(1))),
  all(vapply(folds, function(x) length(x$teste) == 200L, logical(1))),
  all(vapply(
    folds,
    function(x) length(intersect(x$treino, x$teste)) == 0L,
    logical(1)
  ))
)

resumo_folds <- data.frame(
  Fold = seq_len(N_FOLDS),
  Treinamento = vapply(folds, function(x) length(x$treino), integer(1)),
  Teste = vapply(folds, function(x) length(x$teste), integer(1))
)

6. Preparação para a futura redução de n

A redução de n não faz parte da etapa inicial. Entretanto, a permutação ordem_individuos é armazenada para que a expansão futura do projeto possa construir tamanhos amostrais aninhados sem gerar uma nova ordem de indivíduos.

Dessa forma, a futura análise de n x p poderá reutilizar o mesmo desenho experimental em vez de redefinir as amostras após os primeiros resultados.

8. Síntese do desenho inicial

A etapa inicial do projeto fica definida por:

\[ n=1000 \]

e

\[ p\in\{4010,2005,1003,401,201,40\}. \]

A avaliação será realizada por uma única validação cruzada de cinco folds, mantendo 800 indivíduos para treinamento e 200 para teste em cada fold.

Os mesmos folds serão usados por todos os métodos e cenários. A seleção dos marcadores será realizada posteriormente dentro de cada conjunto de treinamento, sem acesso ao fenótipo do conjunto de teste, ao valor genético verdadeiro ou às posições conhecidas dos QTL.

Esse objeto constitui a entrada comum dos módulos de GBLUP e aprendizado de máquina.
