Objetivo

Comparar o desempenho preditivo dos seis métodos considerados no projeto e avaliar sua robustez à redução do número de marcadores (p), mantendo fixo o número total de 1.000 indivíduos.

Nesta primeira fase são comparados:

  • GBLUP aditivo;
  • MARS;
  • árvore de regressão;
  • Bagging;
  • Random Forest;
  • Boosting.

Para cada cenário, método e fold, o painel completo com 4.010 SNPs é utilizado como referência. O desempenho dos painéis contendo 50%, 25%, 10%, 5% e 1% dos marcadores é comparado ao respectivo desempenho com 100% dos SNPs.

A redução do número de indivíduos (n) e a avaliação conjunta de n e p constituem fases posteriores do projeto e não são analisadas neste módulo.

1. Escopo da Fase 1

A análise desta página responde a duas perguntas principais:

  1. qual método apresenta maior capacidade preditiva em cada cenário?
  2. quanto dessa capacidade é preservada quando o número de marcadores é reduzido?

O desenho permanece fixo em

\[ n = 1000 \]

indivíduos e seis níveis de p:

\[ p \in \{ 4010,\ 2005,\ 1003,\ 401,\ 201,\ 40 \}. \]

Os níveis correspondem, respectivamente, a

\[ 100\%,\ 50\%,\ 25\%,\ 10\%,\ 5\%,\ 1\%. \]

Todos os métodos utilizam os mesmos cinco folds. Em cada fold:

  • 800 indivíduos possuem fenótipos disponíveis para treinamento;
  • 200 indivíduos possuem fenótipos ocultos e são utilizados no teste;
  • nos métodos de aprendizado de máquina, o ranking de marcadores é construído apenas com os indivíduos de treinamento;
  • no GBLUP, os 1.000 indivíduos são considerados previamente genotipados e a matriz de relacionamento genômico é construída de forma transdutiva, enquanto os fenótipos dos 200 indivíduos de teste permanecem ocultos;
  • os valores genéticos verdadeiros são utilizados somente para avaliação.

Assim, todos os métodos compartilham exatamente as mesmas partições treino-teste, embora o GBLUP utilize os genótipos dos indivíduos de teste na matriz de relacionamento, conforme documentado em 02_gblup.Rmd.

ler_resultado_grid <- function(
  cenario,
  fold,
  metodo,
  pct
) {

  arquivo <- file.path(
    root_grid,
    cenario,
    sprintf(
      "fold%02d",
      fold
    ),
    metodo,
    p_files[[pct]]
  )

  if (!file.exists(arquivo)) {
    stop(
      "Arquivo ausente: ",
      arquivo
    )
  }

  x <- readRDS(
    arquivo
  )

  stopifnot(
    is.list(x),
    all(
      c(
        "meta",
        "config",
        "metrics",
        "predictions",
        "selected_marker_indices"
      ) %in% names(x)
    )
  )

  m <- x$metrics

  data.frame(
    cenario = cenario,
    fold = as.integer(fold),
    metodo = metodo,
    percentual_p = as.integer(pct),
    p = as.integer(
      x$meta$p
    ),
    n_treino = as.integer(
      x$meta$n_train
    ),
    n_teste = as.integer(
      x$meta$n_test
    ),
    seed = as.integer(
      x$meta$seed
    ),
    runtime_seconds = as.numeric(
      x$meta$runtime_seconds
    ),
    r_true_g = as.numeric(
      m$r_true_g
    ),
    rmse_true_g = as.numeric(
      m$rmse_true_g
    ),
    mae_true_g = as.numeric(
      m$mae_true_g
    ),
    bias_true_g = as.numeric(
      m$bias_true_g
    ),
    slope_true_g = as.numeric(
      m$slope_true_g
    ),
    r2_true_g = as.numeric(
      m$r2_true_g
    ),
    r_phenotype = as.numeric(
      m$r_phenotype
    ),
    rmse_phenotype = as.numeric(
      m$rmse_phenotype
    ),
    stringsAsFactors = FALSE
  )
}

6. Métricas de robustez

A correlação entre o valor genético verdadeiro e a predição é a métrica principal:

\[ r = \operatorname{cor} \left( \mathbf{g}, \widehat{\mathbf{g}} \right). \]

Para cada combinação de cenário, método e fold, o painel com 4.010 SNPs é a referência.

A perda em correlação é definida por

\[ \Delta r_q = r_{100\%} - r_q. \]

A interpretação é:

  • \(\Delta r_q > 0\): redução de desempenho;
  • \(\Delta r_q = 0\): manutenção do desempenho;
  • \(\Delta r_q < 0\): desempenho superior ao painel completo.

Para o RMSE:

\[ \Delta RMSE_q = RMSE_q - RMSE_{100\%}. \]

Valores positivos indicam aumento do erro.

7. Resumo entre folds

Os resultados finais são sintetizados entre os cinco folds. O fold permanece a unidade de replicação da validação cruzada.

media_segura <- function(x) {
  mean(
    x,
    na.rm = TRUE
  )
}

sd_seguro <- function(x) {
  stats::sd(
    x,
    na.rm = TRUE
  )
}

resumir_variavel <- function(
  dados,
  variavel
) {

  grupos <- interaction(
    dados$cenario,
    dados$metodo,
    dados$percentual_p,
    drop = TRUE,
    lex.order = TRUE
  )

  media <- tapply(
    dados[[variavel]],
    grupos,
    media_segura
  )

  desvio <- tapply(
    dados[[variavel]],
    grupos,
    sd_seguro
  )

  n <- tapply(
    dados[[variavel]],
    grupos,
    length
  )

  chave <- unique(
    dados[
      ,
      c(
        "cenario",
        "metodo",
        "percentual_p"
      )
    ]
  )

  chave$grupo <- interaction(
    chave$cenario,
    chave$metodo,
    chave$percentual_p,
    drop = TRUE,
    lex.order = TRUE
  )

  chave$media <- as.numeric(
    media[
      as.character(
        chave$grupo
      )
    ]
  )

  chave$sd <- as.numeric(
    desvio[
      as.character(
        chave$grupo
      )
    ]
  )

  chave$n <- as.integer(
    n[
      as.character(
        chave$grupo
      )
    ]
  )

  chave$grupo <- NULL

  chave
}

15. Robustez preditiva e estabilidade relativa

Robustez não deve ser reduzida a uma única medida de perda em relação ao próprio baseline.

Um método com desempenho inicial baixo pode apresentar \(\Delta r\) próximo de zero simplesmente porque seu nível de predição muda pouco. Por isso, esta fase separa duas dimensões:

  1. robustez preditiva global: desempenho absoluto médio nos cinco painéis reduzidos;
  2. estabilidade relativa: perda média de correlação em relação ao próprio painel completo.

A robustez preditiva global é uma síntese descritiva operacional deste estudo. Para cada método, ela atribui peso igual às 150 células cenário × fold × painel reduzido (6 cenários × 5 folds × 5 níveis de p). Ela não representa um teste estatístico de superioridade entre métodos.

auditar_invariancia <- function(modelo) {

  linhas <- vector(
    "list",
    length(cenarios) * length(folds)
  )

  k <- 0L

  for (cenario in cenarios) {

    for (fold in folds) {

      k <- k + 1L

      d <- file.path(
        root_grid,
        cenario,
        sprintf(
          "fold%02d",
          fold
        ),
        modelo
      )

      ranking <- readRDS(
        file.path(
          d,
          "ranking.rds"
        )
      )

      p100 <- readRDS(
        file.path(
          d,
          "p100.rds"
        )
      )

      p10 <- readRDS(
        file.path(
          d,
          "p010.rds"
        )
      )

      p1 <- readRDS(
        file.path(
          d,
          "p001.rds"
        )
      )

      stopifnot(
        nrow(ranking) == 4010L,
        is.null(
          p100$selected_marker_indices
        ),
        length(
          p10$selected_marker_indices
        ) == 401L,
        length(
          p1$selected_marker_indices
        ) == 40L,
        identical(
          as.integer(
            p10$selected_marker_indices
          ),
          as.integer(
            ranking$marker_index[
              seq_len(401L)
            ]
          )
        ),
        identical(
          as.integer(
            p1$selected_marker_indices
          ),
          as.integer(
            ranking$marker_index[
              seq_len(40L)
            ]
          )
        )
      )

      imp_pos <- ranking$importance_raw > 0

      n_pos <- sum(
        imp_pos,
        na.rm = TRUE
      )

      max_rank_pos <- if (n_pos > 0L) {
        max(
          ranking$rank[
            imp_pos
          ]
        )
      } else {
        NA_integer_
      }

      pred100 <- p100$predictions$predicted_value
      pred10 <- p10$predictions$predicted_value
      pred1 <- p1$predictions$predicted_value

      stopifnot(
        length(pred100) == 200L,
        length(pred10) == 200L,
        length(pred1) == 200L
      )

      diff10 <- max(
        abs(
          pred100 - pred10
        )
      )

      diff1 <- max(
        abs(
          pred100 - pred1
        )
      )

      linhas[[k]] <- data.frame(
        modelo = modelo,
        cenario = cenario,
        fold = fold,
        importancia_positiva = n_pos,
        maior_rank_importancia_positiva = max_rank_pos,
        maxdiff_pred_100_10 = diff10,
        maxdiff_pred_100_1 = diff1,
        pred_100_10_identica = diff10 < 1e-12,
        pred_100_1_identica = diff1 < 1e-12,
        stringsAsFactors = FALSE
      )
    }
  }

  do.call(
    rbind,
    linhas
  )
}

20. Interpretação dos resultados

Os resultados mostram que o método com maior correlação média depende conjuntamente da arquitetura genética e da densidade de marcadores.

Com o painel completo, Boosting apresenta a maior correlação média em C1 (0,9130), Random Forest em C2 (0,7736) e GBLUP em C3, C4, C5 e C6, com correlações médias de 0,8056, 0,8506, 0,8577 e 0,8930, respectivamente.

Ao considerar conjuntamente os cinco painéis reduzidos, o ranking descritivo de robustez preditiva é:

  1. Boosting, com correlação média de 0,80628;
  2. Bagging, com 0,79063;
  3. Random Forest, com 0,78655;
  4. GBLUP, com 0,73752;
  5. MARS, com 0,63717;
  6. árvore de regressão, com 0,43600.

Esse ranking deve ser distinguido da estabilidade relativa em relação ao próprio baseline. O MARS apresenta perda média de correlação igual a zero e, portanto, ocupa a primeira posição em estabilidade relativa, mas apenas a quinta posição em robustez preditiva. A auditoria mostrou que essa invariância decorre de exatamente 10 SNPs com importância positiva, todos preservados até o painel mínimo de 40 marcadores.

A redução extrema para 1% evidencia a mudança de comportamento entre os métodos. Boosting apresenta a maior correlação média nos seis cenários nesse nível de p, variando de 0,6515 em C2 a 0,9277 em C1. Em contraste, o GBLUP apresenta maior sensibilidade à redução severa, especialmente nas arquiteturas mais poligênicas. Em C6, a correlação diminui de 0,8930 no painel completo para 0,5784 com 1% dos marcadores.

Também ocorrem mudanças do método com maior correlação média ao longo da trajetória de redução. O GBLUP apresenta a maior média principalmente em C3–C6 sob alta densidade, enquanto Boosting passa a apresentar a maior média em mais cenários à medida que a redução se torna severa. Em C2, Random Forest apresenta a maior média no painel completo e em 50%, Bagging nos níveis intermediários e Boosting em 1%.

Essas classificações são descritivas; não foram realizados testes formais de diferença entre métodos. Portanto, expressões como “maior correlação média” referem-se aos valores observados entre os cinco folds e não implicam superioridade estatística.

Assim, robustez deve ser interpretada conjuntamente em termos de:

  • desempenho absoluto nos painéis reduzidos;
  • perda relativa em relação ao próprio baseline;
  • arquitetura genética;
  • intensidade da redução de p;
  • variabilidade entre folds.

21. Síntese da Fase 1

Na Fase 1, nenhum método apresenta a maior correlação média em todas as combinações de arquitetura genética e densidade de marcadores.

Com alta densidade, o GBLUP apresenta as maiores médias em C3–C6, enquanto Boosting apresenta a maior média em C1. À medida que o número de marcadores diminui, Boosting passa a ocupar a primeira posição em um número crescente de cenários e apresenta a maior robustez preditiva global segundo a síntese descritiva adotada neste estudo.

No nível mais extremo de redução, com apenas 40 dos 4.010 SNPs originais, Boosting apresenta a maior correlação média em todos os seis cenários. Esse resultado mostra, nestes dados simulados e sob o protocolo adotado, que a seleção de marcadores orientada pelo método pode preservar informação preditiva relevante mesmo sob reduções muito intensas de p.

A estabilidade relativa não deve ser confundida com desempenho preditivo. MARS ilustra essa distinção: permanece numericamente invariável porque utiliza um subconjunto muito pequeno de SNPs, porém apresenta desempenho absoluto inferior ao de Boosting, Bagging, Random Forest e, em vários cenários, GBLUP.

Os resultados desta fase estabelecem o protocolo e a referência para as etapas posteriores de redução de n e da combinação n × p. Essas etapas devem preservar:

  • partições treino-teste rigorosamente definidas;
  • ausência de fenótipos e valores genéticos verdadeiros do teste no ajuste e no ranking;
  • uso explícito e documentado dos genótipos do teste quando o método for transdutivo, como no GBLUP;
  • validação cruzada comum entre métodos;
  • painéis aninhados;
  • métricas de desempenho e robustez previamente definidas;
  • consolidação em objetos versionáveis e auditáveis.
